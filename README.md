# .github

Oakestra is an open-source lightweight orchestration framework for edge and cloud environments, designed to deploy and manage distributed applications across heterogeneous infrastructure.

This repository holds org-wide GitHub configuration: reusable workflow templates under [`.github/workflows`](.github/workflows), Dependabot config, and the organization profile page rendered at [github.com/oakestra](https://github.com/oakestra), whose source lives in [`profile/README.md`](profile/README.md).
